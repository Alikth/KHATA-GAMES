# KHATA GAMES — v7

Built from the existing KHATA GAMES v6 application and restyled against the supplied KHATA / Kill The King visual references.

## Included
- Login / account creation
- Game lobby
- Kill The King realm interface
- Westeros-only region map
- 10 realm markers
- Region -> castles -> castle details flow
- Telegram username registration
- My Castles
- Admin panel
- Sword cursor
- Dark cinematic red/silver visual system
- Wizard transition/background treatment

## Run
```bash
npm install
npm start
```
Then open `http://localhost:3000`.
